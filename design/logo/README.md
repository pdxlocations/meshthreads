# MeshThreads identity

Two-tone Harbor wordmark: teal Mesh, pale blue Threads in dark mode, navy Threads in light mode. Linked speech bubbles represent connected conversations. The header uses the bundled Nunito Sans font.

- [Dark wordmark](meshthreads-dark.svg)
- [Light wordmark](meshthreads-light.svg)
- App favicon: ../../static/images/meshthreads.svg
- PNG app icons: 180, 192 and 512 pixels in static/images.

Created as editable SVG and CSS. The header renders live type using the bundled font; standalone SVG previews use Nunito Sans with an Arial fallback.
