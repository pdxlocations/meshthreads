# Node directory layout concepts

Created with the built-in imagegen tool. Concept 04 (Grouped roster) is implemented in the node directory, with starred groups, expandable details, search, filters and sorting. The other images remain visual explorations. Labels, metadata and artwork in generated concepts are illustrative.

Layout: Title top left: 01 / Compact table. Dense clean directory table, no cards. Columns star, Node (avatar + long name with short name and hex ID below), Role, Last heard, Hops, Actions. Subtle horizontal dividers, fixed aligned columns, generous horizontal room for long names, minimal vertical padding. No duplicated detail panel.
