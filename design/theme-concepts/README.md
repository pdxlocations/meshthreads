# Friendlier MeshThreads theme concepts

Generated using the built-in image generation tool. These are visual concepts. Harbor was selected and is now implemented in the
live app, with both light and dark modes.

1. [Woodland](01-woodland.png): Source Sans 3, forest green, warm cream and sage.
2. [Lamplight](02-lamplight.png): DM Sans, warm charcoal, oatmeal and terracotta.
3. [Field Notes](03-field-notes.png): Lora headings with Inter body, paper and olive.
4. [Harbor](04-harbor.png): Nunito Sans, pale blue-gray, navy and teal.

Prompt set: create four high-fidelity, flat, landscape MeshThreads desktop UI
mockups with the same compact three-column message board. Left rail: profile
selection and rooms; navigation in order Join by URL, Direct messages, Network
map, Node directory, Profiles. Center: MeshOregon thread board, regular-weight
body text, visible Reply links independent of timestamps, expanded replies and
a pinned composer. Right rail: node search, avatars, DM and Invite to room
controls. Use approachable sans-serif typography (a restrained serif heading
for Field Notes), lightweight hierarchy, small rounded cards and subtle borders.
No terminal effects, pixel fonts, neon, heavy bold, large hero or slogans.
Use each concept's typeface and palette listed above.

The fonts and text in AI mockups are illustrative; final UI typography will use
real fonts and actual application data.
