# Example screenshots

Captured from the actual MeshThreads interface on 2026-10-31 using an isolated local database and fictional profiles, nodes, messages, telemetry and traceroutes. Radio transport was mocked or stopped. No live account data, private channel keys, or real conversations are shown.

- `board-dark.png`: desktop threaded board, Harbor dark mode.
- `board-light.png`: desktop threaded board, Harbor light mode.
- `node-directory.png`: grouped roster with expanded telemetry, traceroute and map.
- `board-mobile.png`: phone-width conversation view (393 × 852 CSS viewport).
- `mobile-navigation.png`: compact navigation drawer at the same phone width.

Browser chrome was cropped from native browser captures. Desktop captures were resized for documentation; no generated mockups were substituted for screenshots. Node directory capture uses a wider effective viewport through browser zoom.

Map tiles/data: © OpenStreetMap contributors (https://www.openstreetmap.org/copyright); mapping UI: Leaflet.
