# Example screenshots

Captured from the actual MeshThreads interface using an isolated local database and fictional profiles, nodes, messages, telemetry and traceroutes. Radio transport was mocked or stopped. No live account data, private channel keys, or real conversations are shown.

- `board-dark.png`: desktop threaded board, Harbor dark mode, refreshed 2026-11-01.
- `board-light.png`: the same fuller conversations and tapbacks in Harbor light mode, refreshed 2026-11-01.
- `node-directory.png`: grouped roster with expanded telemetry, traceroute and map, captured 2026-10-31.
- `board-mobile.png`: phone-width conversation view with nested replies and tapbacks, refreshed 2026-11-01.
- `tapbacks-mobile.png`: a tapped emoji bubble showing its two senders, captured 2026-11-01.
- `mobile-navigation.png`: compact navigation drawer alongside the same conversations, refreshed 2026-11-01.

The refreshed demo contains three conversations with 15 text posts and 11 emoji reactions. Desktop views use a 1440 × 1000 CSS viewport; phone views use the iPhone 16 preset at 393 × 852. Captures use Chrome's viewport screenshot command through the native browser UI, then are resized for documentation. The older node directory capture was cropped from a native browser screenshot and uses a wider effective viewport through browser zoom. No generated mockups were substituted for screenshots.
